# Fraud and Security SOP (Demo)

> Mock demo SOP for Samadhan. Not a real fraud operations policy.

## Purpose

Guide urgent fraud and unauthorized transaction reports.

## Key points

- Treat all fraud and security reports as critical priority.
- Record a mock protective action for demo purposes only; do not claim a real account or card freeze.
- Check recent transactions using internal mock records before responding.
- Always escalate to Human Review for security cases.
- Tell the customer their report is logged and under security review.
